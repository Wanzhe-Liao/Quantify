## 统一口径

每标的独立1,000 USDT资本，固定25%虚拟总库存预算；无马丁加仓或杠杆升级。Maker 2 bps，taker 5 bps，市价滑点5 bps；计入缓存中的实际资金费率和资金费结算标记价。模拟maker成交量不超过当分钟成交量的1%。期末全部平仓。

中心价位现在可以作为配对退出价位，但本轮是新的paired-rung引擎，不是旧字典网格的等价复现。原代码和报告保留。

闭市时段排除竞价及盘后交易：HKEX按09:00-12:00、13:00-16:10；SSE按09:15-11:30、13:00-15:30（当地时间）划定非闭市区间。

## 复现与边界

```bash
pip install -r requirements-lab.txt
pytest -q
python scripts/run_grid_lab.py
```

输出包括完整候选逐窗口结果、开发/审计/全历史摘要、冻结优选、每周选参记录、各时期分解、执行压力、权益轨迹、配置与协议哈希。CI产物附依赖锁定快照、pytest XML和完整日志。

一分钟OHLC不能验证盘口队列、完整插针路径或实际成交。两种顺序下较差结果不是所有tick路径的严格下界。止损按已完成K线触发、下一根开盘执行，跳空损失可超过止损阈值。历史tick/lot过滤器变化、具体账户费率和真实强平标记价尚未完整重建。

本轮没有实盘下单，没有合并main，也没有启动无期限自动调参。下一轮需要新的可证伪假设与未用于选择的后续数据；逐笔/盘口成交验证优先于继续在这批已看过的数据上扩大参数搜索。
